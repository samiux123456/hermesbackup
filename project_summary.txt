پروژه: بازی گروهی اسم و فامیل تلگرامی
نسخه: ۱.۰ نهایی و کامل

========================================
خلاصه پروژه:
========================================

یک بات تلگرامی برای اجرای بازی گروهی اسم‌وفامیل در گروه‌های تلگرامی.
حداکثر ۲۰ بازیکن همزمان، ۳ راند، ۵ دسته (اسم، فامیل، شهر، کشور، حیوان)، ۶۰ ثانیه زمان هر راند.
ثبت جواب مخفی از طریق DM (چت خصوصی با بات)، امتیازدهی پله‌ای.
قابل اجرا روی سرورهای ساده با SQLite و In-Memory State.

========================================
تصمیمات نهایی (تأیید شده):
========================================

۱. روش ثبت جواب: DM (چت خصوصی با بات) - نه Force Reply در گروه
   (Force Reply مخفی نیست و همه در گروه جواب رو می‌بینند)
۲. امتیازدهی: پله‌ای عدد صحیح (۱۵، ۱۰، ۵، ۳، ۰)
۳. اجرای بات: Polling (نه Webhook) - ساده‌تر برای MVP
۴. معماری State: Repository Interface با In-Memory برای MVP
۵. معماری کلی: ۴ لایه با جداسازی کامل
۶. زمان هر راند: ۶۰ ثانیه (قابل تنظیم)
۷. تعداد راندها: ۳ (قابل تنظیم)
۸. دسته‌ها: اسم، فامیل، شهر، کشور، حیوان
۹. حروف: الفبا (به جز حروف سخت ذ، ظ، ع، غ، ژ، ث)
۱۰. نرمال‌سازی فارسی: حذف اعراب، فاصله‌های اضافی، ی/ک

========================================
معماری ۴ لایه:
========================================

لایه ۱: Interface (telegram handlers, keyboards, messages)
لایه ۲: Application (GameService, RoundService, AnswerService)
لایه ۳: Domain / Game Engine (GameEngine, ScoringEngine, Normalizer, Validator)
لایه ۴: Infrastructure (StateRepository, WordRepository, Database)

========================================
تکنولوژی‌ها:
========================================

- Python 3.11+
- python-telegram-bot v20+ (Async)
- SQLite + aiosqlite
- In-Memory State
- Loguru (لاگ)
- Pydantic (config)
- pytest + pytest-asyncio (تست)

========================================
جریان کلی بازی:
========================================

۱. میزبان /newgame میزنه → لابی ساخته میشه
۲. بازیکنان join میکنن
۳. میزبان start میزنه → شمارش معکوس
۴. راند ۱ شروع: حرف تصادفی انتخاب میشه
۵. بات به هر بازیکن DM میفرسته: «اسم با حرف X چیه؟»
۶. بازیکنان در DM جواب میدن
۷. ۶۰ ثانیه تمام میشه → نتایج راند نمایش داده میشه
۸. راند ۲ و ۳ تکرار میشه
۹. پایان بازی → رتبه‌بندی نهایی

========================================
State Machine:
========================================

بازی: lobby → ready → playing → finished
راند: waiting → active → ended
بازیکن: joined → ready → playing → submitted → finished
جواب: draft → submitted → final → evaluated
